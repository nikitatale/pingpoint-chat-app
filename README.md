# PingPoint 🚀

PingPoint is a **full-stack real-time chat application** built with modern technologies for seamless and secure communication. 
It features real-time messaging, media sharing, and user authentication.

---

## Features ✨
- **Real-Time Chat:** Send and receive messages instantly.
- **User Authentication:** Secure sign-in and sign-up powered by Clerk.
- **Media Sharing:** Upload images via ImageKit.
- **Redux State Management:** Efficient handling of messages and user data.
- **Responsive UI:** Built with React and TailwindCSS for smooth experience across devices.
- **Notifications:** Real-time notifications using React Hot Toast.
- **Backend APIs:** RESTful APIs with Express and MongoDB for persistent storage.
- **File Uploads:** Handled with Multer and ImageKit for media management.

---

## Tech Stack 🛠️

**Frontend:**
- React  
- Vite  
- Redux Toolkit  
- TailwindCSS  
- React Router DOM  
- Clerk for authentication  

**Backend:**
- Node.js  
- Express  
- MongoDB  
- Clerk for authentication  
- Multer for file uploads  
- ImageKit for media storage  
- Nodemailer for email notifications  

**Other Tools:**
